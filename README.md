# Oude Molen Technical High School — Reece Digital independent concept

Review build **1.0**. Built against Master Blueprint V3 using isolated HTML/CSS/JS and the supplied dimensional crest. Twelve pages, including dedicated technical workshops, local demo staff studio, calendar, gallery, documents, admissions and contact tools. Not the official school website.

## Review
Extract the folder. Open `index.html` in Firefox or serve the folder with `python3 -m http.server 8000` and visit `http://localhost:8000/` for consistent origin-local data. Staff demo credentials: `staff` / `demo123`. Use fictional information only. Browser-local records do not sync or publish to the internet.

## Sources and limitations
School information from https://www.oudemolen.org.za/. See `data/school.json`, `data/media.json` and `docs/SOURCE_MANIFEST.md`. Original remote photographs were visually inspected via the source browser, but this build environment cannot retrieve their bytes. The site references exact source-image URLs and uses distinctly labelled local source panels when images fail. Do not publish or repurpose third-party images before permission/rights review. Gallery demo uses an illustration, not a school photograph. Contacts are school-published but not verified via outreach. Example events, notices and document entries are explicitly marked; no actual school documents included. No backend, secure authentication, actual image upload or enquiry delivery.
